# Sales Analytics Dashboard — Excel Portfolio Project

## Project Overview

An Excel-based sales analytics project built to analyze 60 sales orders across four cities, four salespeople, and eight products.

The project uses data cleaning and organization, Excel formulas, lookup functions, PivotTables, and dashboard visualizations to explore sales performance, completed revenue, order status, and product-level trends.

## Objectives

- Analyze sales performance across cities and salespeople.
- Separate completed revenue from pending and cancelled orders.
- Compare product performance.
- Summarize key performance indicators (KPIs).
- Build an interactive, easy-to-read Excel dashboard.

## Tools and Skills

- **Microsoft Excel:** Tables, sorting, filtering, data validation, and conditional formatting.
- **Formulas:** IF, SUMIF, SUMIFS, COUNTIF, COUNTIFS, AND, OR.
- **Lookup and text functions:** VLOOKUP, XLOOKUP, INDEX/MATCH, LEFT, RIGHT, MID, TEXTJOIN.
- **Data analysis:** PivotTables, KPI calculations, and grouped summaries.
- **Visualization:** Dashboard KPI cards, column charts, bar charts, and a doughnut chart.

## Key Performance Indicators

| Metric | Result |
|---|---:|
| Total Orders | 60 |
| Completed Orders | 34 |
| Completed Revenue | ₹48,980 |
| Average Completed Order Value | ₹1,440.59 |
| Pending Orders | 14 |
| Cancelled Orders | 12 |
| Total Order Value Across All Statuses | ₹86,830 |

## Key Findings

- **Coimbatore** generated the highest completed revenue at ₹19,040.
- **Priya** generated the highest completed revenue among salespeople at ₹20,680.
- **Desk Lamp** was the leading product by completed revenue at ₹18,000.
- 34 of 60 orders were completed, while 14 remained pending and 12 were cancelled.
- Completed revenue represented ₹48,980 of the ₹86,830 total order value across all statuses.

## Workbook Structure

- **START_HERE:** Project introduction, key results, and workbook guide.
- **Dashboard:** KPI cards and visual summaries of sales performance.
- **Analysis:** Formula-driven metrics and summaries by city, salesperson, status, and product.
- **Raw_Sales:** The 60 source order records, including calculated revenue and order-level classifications.
- **Product_Master:** Product IDs, names, categories, and unit prices.
- **Pivot_table:** PivotTable summaries for exploring sales and order patterns.

## Business Value

This project demonstrates how spreadsheet tools can transform order-level records into summarized metrics and visual reports. The resulting dashboard helps a viewer quickly understand completed revenue, compare performance, and identify areas that may deserve further investigation.

## Limitations

This is a small portfolio dataset with 60 orders. The findings describe this dataset only and should not be treated as proof of broader market trends or actual company performance.

## Project Outcome

Built an end-to-end Excel sales analytics workbook, from structured source data and formula-based calculations to PivotTable analysis and a dashboard designed for quick business review.
